=========================================================================
GM PROGRAM -> WAVE, READ BACK FROM THE VENDOR RENDERER (probes/VEW2MAP.C)
=========================================================================
The ROM has no GM map and no root notes, so we ask the hardware instead
of reading anyone's driver.  With the vendor DOS stack resident
(OPL4TSR + SCPRODOS /C330 /M388 /I9 + OPL4DRV) the card is on COR index
26h and there is an MPU-401 at 330h.  Send an exact program change and
an exact note, wait, then read which wave the renderer loaded into which
voice and at what pitch.  Only the chip's own registers are examined.

  MPU:  poll 331h until bit6 (DRR) clears, then write 330h
        C0 pp        program change
        90 nn vv     note on        80 nn 00   note off
  OPL4: 08H+v      wave number bits 7:0
        20H+v bit0 wave number bit 8      20H+v 7:1  F-NUM f6..f0
        38H+v 7:4  octave, signed         38H+v 2:0  F-NUM f9..f7
        50H+v 7:1  total level
        68H+v bit7 KEY ON                 68H+v bit4 CH (output pin)

WHAT THE READINGS MEAN
  A wave number that CHANGES as the note rises marks a multisample key
  split.  Octave and F-NUM give the tuning: rate = 2^OCT * (1+FNUM/1024),
  and a sample's root is the note whose rate comes out at 1.0.

FIRST RESULTS - and the cross-check that validates the method
  prog | n36   n48   n60   n72   n84
     0 |  300   302   304   306   308
     1 |  300   301   303   305   307
     2 |  300   301   303   305   307
     3 |  300   302   304   306   308

  Program 0 at note 60 reads wave 304 - identical to the value measured
  by hand over the COMrade link before this tool existed.
  Multisampling is plain: program 0 walks 300-302-304-306-308 up the
  keyboard, exactly the structure the ROM's envelope-group runs implied.
  Programs share banks: 0 and 3 take one sequence, 1 and 2 another - the
  piano family drawing on one multisample set.
  The vendor renderer keys every voice with CH = 0, independently
  confirming that DO2 is the only output wired on this card.
