Differences from the CF-VEW211:
  * MANFID card ID 0x0501 (not 0x0001)
  * VERS_1 branding: Panasonic / Sound Card PRO / CF-VEW212 / Ver 1.0
  * ONE config entry only (last index 0x20): no E80/F40/604 alternates
  * different checksum tuple (naturally)
Everything else — config reg base 0x200 with COR+CCSR, the default
codec 0x530 + FM 0x388 layout, the level-only {7,9,10,11} IRQ set, the
DEVICE_A byte, even the vendor FUNCID 0xFF quirk — matches the VEW211
byte for byte.  Almost certainly the same MEI ASIC family.

Not yet probed (CIS tells us nothing about): codec type at base+4
(expect CS4231-family WSS; check I12 chip ID), FM actually fitted
(declared in the CIS, unlike the fitted-FM-less PC-9801N-J04 whose CIS
declared no 388 range — good sign), vendor regs 0x204/0x206/0x208 /
CIS shadow / EEPROM strobe presence.

HARDWARE (the operator, 2026-07-19): the card has an OPL4 (YMF278) MIDI
WAVETABLE built in, and he believes the YMF262 is ALSO fitted (211
board + wavetable section is the working theory — the OPL4 contains an
OPL3 core, so both chips only makes sense if the 262 keeps the 388
legacy path and the OPL4 serves wave-only duty behind the ASIC).

Where are the wave registers?  The CIS's FM range is still only
388h x4 (no 38C/38D pair a standard OPL4 mapping would use), but the
codec range is len 10 again — and on the VEW211, base+8/+9 was the
hidden vendor bank behind the 0x206=0x38 + 0x208=0x05 combination
lock (fixed 0xA_ upper nibble at +8, 0xBC at +9, no audible effect =
plumbing with nothing behind it).  PRIME SUSPECT: on the 212,
0x538/0x539 (possibly behind the same lock) = OPL4 wave addr/data.
